# Аудит и исправления Iris

Исходный срез: `9991d87`, 2026-10-16. Аудит `src`/`test`, углублённо: chat/runtime, tools, broker, persistence, memory и lifecycle. Production, frontend и нагрузка не проверялись.

Базовая проверка: clj-kondo — 0 замечаний; 818 тестов, 3283 assertions, 0 failures/errors. Восемь дефектов воспроизведены локально, включая подмену транспорта и инъекции ошибок.

## Дефекты

- [ ] **F01 / P1 — shell approval.** `find -exec` выполняет произвольную команду, `sort -o` пишет файл без approval. Ограничить автоматические разрешения безопасными аргументами; сохранить явные пользовательские правила. Регрессии: вложенный executable, запись, обычное чтение.
- [ ] **F02 / P1 — credentials при redirect.** HTTP повторяет Authorization/Cookie на другом origin. Удалять чувствительные заголовки при смене origin; проверять также порт и схему.
- [ ] **F03 / P1 — cancellation race.** Отмена освобождает сессию до завершения worker; старый финал удаляет новый stream. Сохранить владение сессией до завершения, проверять request-id. Регрессия: cancel → следующий запрос → позднее событие.
- [ ] **F04 / P1 — зависшая очередь.** Ошибка event sink после установки active оставляет запрос без worker/result. Разделить изменение состояния и уведомление; гарантировать завершение при отказе executor.
- [ ] **F05 / P1 — потеря сохранённого ответа.** Persistence subscriber проглатывает ошибку и публикует успешный message-end. Обязательная persistence должна прерывать успешное завершение; UI callbacks остаются необязательными.
- [ ] **F06 / P2 — неверный rollback памяти.** Ошибка audit event после applied откатывает файл, оставляя applied в БД. Исправить границу фиксации/отката; проверить ошибку audit и ошибку фиксации статуса.
- [ ] **F07 / P2 — stdout/SIGPIPE.** Reader закрывает pipe на лимите; команда завершается 141. Дочитывать и отбрасывать избыток, возвращать признак усечения, освобождать process/streams при ошибке.
- [ ] **F08 / P2 — невидимые потери broker.** Sliding buffer сохраняет 2 из 5 событий, dropped-count=0. Учитывать вытеснение; обеспечить обнаружение потери terminal events потребителями.

## Code smells

- [ ] **F09 — HTTP memory bound.** Размер проверяется после загрузки всего ответа. Читать поток с ограничением байтов и обязательным закрытием, включая redirects и ошибки.
- [ ] **F10 — неограниченный chat.** Cached thread pool и очередь не ограничены. Добавить пределы параллелизма/очереди, управляемый отказ и тесты насыщения без зависаний.
- [ ] **F11 — состояние и эффекты.** runtime/run! содержит 319 строк, смешивает planning/retries/approval/streaming/fallback; queue смешивает переходы и публикацию. Выделить чистые решения и ограниченные операции исполнения, сохранить поведение.
- [ ] **F12 — дублированная shell policy.** Три источника: shell/default-rules, config/defaults.clj, resources/config/default.edn; уже различаются uname. Оставить один канонический источник.
- [ ] **F13 — глобальное изменяемое состояние.** loop-states и UI stream maps живут в defonce вне lifecycle. Перенести состояние в экземпляр системы, очистку — в stop; проверить изоляцию двух систем.
