# HA Report — растения и климат

## Датчики

| Растение | Влажность | Температура | Батарея |
|---|---|---|---|
| Драцена | `sensor.dratsena_soil_moisture` | `sensor.dratsena_temperature` | `sensor.dratsena_battery` |
| Фикус | `sensor.hobeian_zg_303z_humidity` | `sensor.hobeian_zg_303z_temperature` | `sensor.hobeian_zg_303z_battery` |

| Климат | Датчик |
|---|---|
| Температура | `sensor.gradusnik_temperature` |
| Влажность | `sensor.gradusnik_humidity` |

## Выполнение

1. Одним вызовом `homeassistant` `get_states` запросить все восемь `entity_ids` из таблиц.
2. Одновременно одним вызовом `shell` прочитать последнюю строку вчерашнего файла. Использовать путь `~/iris/ha-logs/ha-report-$(date -d yesterday +%F).jsonl`; отсутствие файла означает, что сравнения нет.
3. Сохранить значения из успешных результатов в рабочем контексте. Не повторять успешный вызов из-за отсутствия сырого payload: `result-text` является достаточным evidence.
4. Если `get_states` сообщает `missing`, показать отсутствующие датчики в отчёте. Не пытаться получать их повторно в этом запуске.
5. Сформировать отчёт и один раз дописать текущую запись в `~/iris/ha-logs/ha-report-YYYY-MM-DD.jsonl`. Создать директорию при необходимости.
6. Завершить ответом пользователю. Не запускать дополнительные discovery/search вызовы: entity IDs уже известны.

Нормальный запуск: два tool calls для чтения, один для записи, два tool-rounds. Никогда не повторять цикл чтения датчиков и вчерашнего файла.

## Формат отчёта

### Растения

Точная шапка таблицы:

```markdown
| Растение | 💧 | 🌡️ | 🔋 |
|---|---:|---:|---:|
```

Показывать влажность почвы (%), температуру (°C), батарею (%).

### Климат

Заголовок `## 🏢 Климат`, затем:

```markdown
| Параметр | Значение |
|---|---:|
```

Добавить компактный вывод: изменение относительно вчерашней последней записи, рекомендации по поливу, замечания по батареям.

## JSONL

Одна строка на запуск:

```json
{
  "timestamp": "2026-08-15T09:00:00+03:00",
  "plants": {
    "dratsena": {
      "soil_moisture_pct": 37.0,
      "temperature_c": 26.0,
      "battery_pct": 58.0
    },
    "ficus": {
      "soil_moisture_pct": 47.0,
      "temperature_c": 24.6,
      "battery_pct": 100.0
    }
  },
  "climate": {
    "temperature_c": 26.0,
    "humidity_pct": 42.1
  }
}
```

Все измерения числовые; `timestamp` — ISO 8601 с таймзоной. Если файл текущей даты существует, дописать строку, не перезаписывать файл.
