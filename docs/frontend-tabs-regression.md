# Исправление вкладок и проверка задержки чата — 2026-10-22

## Вкладки

Добавление `<!doctype html>` включило standards mode. Нулевой SVG
`.ui-card-tab-clip-defs` внутри навигации остался inline-элементом и создал
строку высотой 20 px. Высота навигации стала 58 вместо 38 px: между низом
вкладок и панелью появился зазор 8 px. Старый CSS при новом doctype
воспроизводит тот же дефект — причина не в разделении CSS.

Исправление: `position: absolute` для SVG с определениями clip-path.
SVG остаётся доступен для clipping, но не участвует в расчёте высоты.
Добавлена браузерная проверка: выбранная вкладка перекрывает верх панели,
а подпись остаётся выше панели.

## Задержка чата

Проверена работающая версия `0896c8e` с авторизацией, Chrome на
`anton.tailscale`, приложение на `100.64.0.4:8689`, сессия
`3e2d0a8d-0926-45a4-9805-a8e627e90c3a`.

- Локальный HTTP на сервере: shell чата 41 мс / 33 212 байт;
  фрагмент истории 15 мс / 6 065 байт; overview 155 мс.
- Прямое открытие в браузере: чат 106–187 мс, overview 152–198 мс.
- Переключение Overview → Chat: 154 и 158 мс;
  Memory → Chat: 144 мс. Выбрана та же сессия.
- Ответ `/ui/route?tab=chat` получен через 89–99 мс от начала переключения.

Это несколько наблюдений, не статистический benchmark и не измерение
на устройстве пользователя. Заявленное замедление пока не воспроизведено.
Для дальнейшей диагностики нужны браузер и длительность задержки.

Первичная загрузка истории и `resync=true` live-потока действительно
рендерят историю дважды. Повторная синхронизация закрывает промежуток между
снимком истории и подпиской на события; убирать её без механизма
согласования снимка с подпиской нельзя. В этой сессии её стоимость
не объясняет значительную задержку.

Предыдущая проверка production без авторизации подтверждала только
загрузку shell и ресурсов; её нельзя считать проверкой содержимого страниц.
