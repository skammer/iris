# Автоматические названия чатов

Пустое название получает заголовок после первого обмена сообщениями.
Стандартное название вида `Telegram: имя` — после двух непустых сообщений
пользователя и двух ответов ассистента. Проверка выполняется после завершения
хода; cron-сессии исключены.

LLM получает не более шести сообщений пользователя/ассистента, каждое
ограничено 1200 символами. Заголовок — одна строка до 50 символов на языке
диалога. Пустой ответ или ошибка провайдера оставляют прежнее название;
следующий ход повторит попытку. Генерация использует существующий механизм
`agent.chat.title`, без дополнительного фонового сервиса.

Сохранение — атомарное compare-and-set по предыдущему названию. Ручное
переименование или результат параллельной генерации не перезаписываются.
После сохранения публикуется `session.title.updated`, уже обрабатываемое UI.
Названия с префиксом `Telegram: ` считаются стандартными, в том числе у
старых сессий, где источник названия отдельно не сохранялся.

Для существующих сессий можно однократно вызвать `maybe-generate-title!`
последовательно для кандидатов `default-title?`; те же пороги и проверки
сохраняются. Тексты сообщений не меняются.

## Компактная шапка

Поле проекта занимает правую колонку обеих строк. Слева заголовок и модель
имеют line-height 1.2, промежуток 2 px. В Chrome на Anton высота уменьшилась
с 72 до 47 px при ширине 1280/768 и до 43 px при 390/320; переполнений нет.
Проверены ввод черновика, сохранность стыка вкладок и отсутствие JS-ошибок.
Safari непосредственно не проверялся.

Проверки backend: 30 тестов, 149 assertions, без ошибок; тесты порога,
однократного переименования, ошибки LLM и конкурентного изменения названия.
